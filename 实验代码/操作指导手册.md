## 第二步：ONNX → RKNN 模型转换（10分钟）

这是你**最重要**的一步，把模型转成RK3566能用的格式。

### 操作步骤：

1. **启动Ubuntu虚拟机**

2. **把best.onnx文件传进虚拟机**
   - 方法一：VMware共享文件夹（推荐）
     - VMware → 虚拟机 → 设置 → 选项 → 共享文件夹 → 添加你电脑上的 `实验代码` 文件夹
     - 虚拟机里访问路径：`/mnt/hgfs/实验代码/`
   - 方法二：直接拖拽文件到虚拟机窗口
   - 方法三：用U盘

3. **复制best.onnx到指定目录**
   ```bash
   # 在虚拟机终端中执行
   cp /你的best.onnx路径/best.onnx ~/rknn-toolkit2-master/examples/onnx/yolov5/
   ```

4. **确认目录下有必要文件**
   ```bash
   cd ~/rknn-toolkit2-master/examples/onnx/yolov5/
   ls
   # 应该能看到: best.onnx  dataset.txt  tank.jpg  test.py
   ```
   
   > 如果没有 `tank.jpg`，从训练数据集里随便复制一张坦克图片过来重命名为 `tank.jpg`
   > 如果没有 `dataset.txt`，创建一个：`echo "tank.jpg" > dataset.txt`

5. **激活rknn环境并执行转换**
   ```bash
   conda activate rknn
   python test.py
   ```

6. **等待转换完成**（约2-5分钟）
   - 看到类似 "done" 或 "export rknn success" 的提示就成功了
   - 当前目录下会生成 `best.rknn` 文件

7. **验证生成的文件**
   ```bash
   ls -la best.rknn
   # 应该能看到文件大小约几MB
   ```

> **如果test.py报错**，可以试试用我准备的脚本：
> ```bash
> cp /共享文件夹路径/convert_onnx_to_rknn.py .
> python convert_onnx_to_rknn.py
> ```

**恭喜！best.rknn 就是最终的部署模型文件。** 把它拷出虚拟机备用。

## 第三步：实验3.3 — RK3566系统镜像烧录（15分钟）

> 前提：你有RK3566开发板和USB数据线

### 操作步骤：

1. **找到烧录工具**
   - 解压 `资源包/PC端软件安装文件.zip`
   - 里面应该有 RKDevTool（瑞芯微开发工具），如果没有可以网上下载

2. **找到系统镜像文件**
   - 就是你从百度网盘下载的RK3566镜像（第一步1.5中下载的）

3. **打开RKDevTool**

4. **配置烧录参数**
   - 勾选启动项（boot）
   - 起始地址设为 `0x0000`
   - 点击路径按钮，选择你的镜像文件
   - 点击"强制按地址写"

5. **连接开发板**
   - USB线一端插电脑，Type-C端插RK3566开发板

6. **让开发板进入下载模式**（关键操作！）
   - **长按REC键**（不要松手）
   - 同时**短按一下RST键**
   - **松开REC键**
   - 软件左下方应该显示"发现一个LOADER设备"

7. **点击"执行"按钮**
   - 右侧会显示下载进度
   - **耐心等待**，不要断开USB线！
   - 进度条到100%，提示"下载完成"就OK了

8. **断开数据线，烧录完成**

## 第四步：实验3.2 — 飞控固件升级及参数烧录（20分钟）

> 前提：你有Pixhawk飞控和USB数据线，已安装Mission Planner

### 操作步骤：

1. **连接飞控**
   - USB数据线连接Pixhawk飞控和电脑
   - 打开Mission Planner
   - 右上角选择识别到的COM口（如COM11）
   - 波特率选 `115200`
   - 点击"连接"

   > 如果连不上：检查COM口是否选对、是不是数据线（不是充电线）

2. **查看当前固件版本**
   - 点击上方"消息（Messages）"栏
   - 可以看到当前固件版本号

3. **升级固件**
   - **先断开连接**
   - 进入"初始设置" → "安装固件"
   - 选择你的机架类型对应的最新固件（如4.6.3）
   - 点击"继续"
   - 等待下载和安装完成
   - 左下角显示"升级成功"即完成

   > 升级过程中**不要碰USB线**！松动会导致COM口号变化

4. **加载基础参数**
   - 重新连接飞控
   - 进入"配置/调试" → "全部参数表"
   - 点击"加载"
   - 选择老师提供的参数文件（.param格式）
   - 点击"OK"和"Yes"
   - **重要：点击"写入参数"**（否则重启后参数丢失）
   - 可选：点击"保存"备份当前参数

5. **加载航点文件**
   - 进入"飞行计划"页面
   - 点击"加载航点文件"
   - 选择老师提供的 `.waypoints` 文件
   - 点击"写入航点"完成导入

## 第五步：实验6.3后半段 — 部署模型到RK3566（15分钟）

> 前提：RK3566已烧录好系统（第三步），best.rknn已生成（第二步）

### 操作步骤：

1. **打开MobaXterm**

2. **SSH连接RK3566开发板**
   - 点击"Session" → "SSH"
   - 输入RK3566的IP地址（问老师或用网线直连时默认IP）
   - 输入用户名和密码

3. **上传best.rknn到开发板**
   - MobaXterm左侧有文件浏览器，直接拖拽上传
   - 或者用命令：
   ```bash
   scp best.rknn user@<RK3566的IP>:/path/to/deploy/
   ```
   - 具体路径参考课程PDF 6.3中图6.50所示的位置

4. **连接摄像头到RK3566**

5. **启动摄像头节点**
   ```bash
   roslaunch rknn_ros camera.launch device:=video0
   ```
   > 如果video0不行，先查看可用设备：`ls /dev/video*`

6. **另开一个终端，启动YOLO识别**
   ```bash
   roslaunch rknn_ros yolov5.launch chip_type:=RK356X
   ```
   - 终端会显示是否识别到目标以及识别精度

7. **查看识别效果（可选）**
   ```bash
   # 再开一个终端
   rqt_image_view
   ```
   - 在打开的窗口选择 `/rknn_image/theora`
   - 可以看到实时的坦克识别画面

## 第六步：实验5.1 — PCB焊接（在实验室做，1-2小时）

> 这个实验需要在实验室操作，没法远程做

### 焊接前准备：

1. **看懂原理图和PCB的对应关系**
   - 原理图定义电气连接逻辑
   - PCB是物理实现
   - 资源包里有完整的AD工程文件：`资源包/嵌入式系统硬件文件.zip`
   - 解压后有 `器件焊接坐标以及bom表/器件坐标.html`（交互式BOM，很好用！）

2. **识别元器件方向**
   - 4G模块：找到模块上的1号引脚标识（小圆点或三角标记）
   - USB HUB芯片：同样找1号引脚标识
   - 二极管：有一条横线的一端是负极
   - 电容：无极性（随便放）
   - 电阻：无极性（随便放）

### 焊接操作：

3. **工具设置**
   - 焊枪温度：350-380°C（普通器件）/ 380-400°C（密集引脚）
   - 热风枪：风速1-3档，温度300-420°C
   - 加热台：200-250°C

4. **焊接顺序**（一般从小到大）
   - 先焊贴片电阻、电容（小元件）
   - 再焊IC芯片（USB HUB等）
   - 最后焊接大型模块（4G模块、排插等）

5. **焊接要点**
   - 先在焊盘上上锡
   - 用镊子夹住元件放到位
   - 烙铁头接触焊盘加热，让焊锡自然流到引脚
   - 焊完检查有没有虚焊、桥接

6. **焊后检查**
   - 目视检查所有焊点
   - 用万用表测试关键通路
   - 确认没有短路

## 常见问题

**Q: 虚拟机里找不到rknn-toolkit2-master目录？**
A: 可能在桌面或home目录下，试试 `find / -name "rknn-toolkit2-master" -type d 2>/dev/null`

**Q: conda activate rknn 报错？**
A: 先试 `source activate rknn` 或 `conda init bash && source ~/.bashrc && conda activate rknn`

**Q: Mission Planner连不上飞控？**
A: 检查三件事：COM口选对没、波特率115200、用的是数据线不是充电线

**Q: RKDevTool识别不到设备？**
A: 确保按键顺序正确：先长按REC → 再短按RST → 再松开REC。如果还不行，换个USB口试试

**Q: 运行detect.py时提示没有GPU？**
A: 可以用CPU跑，只是慢一点：`python detect.py --weights runs/train/exp20/weights/best.pt --source datasets/images/val --device cpu`
