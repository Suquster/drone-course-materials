## 关键烧录流程

### 飞控固件升级 (Mission Planner)
1. 连接Pixhawk飞控 -> 选择COM端口
2. 初始设置 -> 安装固件 -> 选择机架类型
3. 等待固件下载和安装完成
4. 加载参数文件

### RK3566开发板系统烧录
1. 打开RKDevTool烧录工具
2. 加载系统镜像文件
3. USB连接开发板
4. 长按REC键 + 短按RST键进入下载模式
5. 识别到LOADER设备后点击"执行"

### YOLO模型部署
1. 训练: `python train.py --data data/ccsszz.yaml --weights yolov5s.pt --epochs 300`
2. 导出ONNX: `python export.py --rknpu --weight best.pt`
3. 转换RKNN: 使用rknn-toolkit2转换为NPU加速格式
4. 部署到RK3566开发板
